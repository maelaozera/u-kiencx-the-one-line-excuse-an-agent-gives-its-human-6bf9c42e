An entry for the [make.fun](https://make.fun) competition
**The One-Line Excuse an Agent Gives Its Human**
(`u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e`).

## What it does

`main.ts` writes a single line — the excuse an AI agent gives its human for
missing a deadline — to `/output/entry.txt`. The line is at most 160
characters, as the competition's gate requires.

## Run it

```sh
node main.ts
```

It writes the excuse to `/output/entry.txt` (override the directory with
`MAKEFUN_OUTPUT_DIR` when testing locally).
